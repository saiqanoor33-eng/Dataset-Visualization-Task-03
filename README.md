# Dataset-Visualization-Task-03
Created five meaningful data visualizations using Python, Pandas, and Matplotlib, including bar chart, line chart, pie chart, histogram, and scatter plot.
# Dataset Visualization — Task 03

## Overview

This project focuses on creating meaningful data visualizations from a cleaned movie dataset using Python.

## Technologies Used

* Python
* Pandas
* Matplotlib

## Dataset

The dataset contains movie information including:

* Movie title
* Genre
* Release year
* Rating

## Visualizations Created

1. **Bar Chart** — Number of Movies by Genre
2. **Line Chart** — Number of Movies by Year
3. **Pie Chart** — Movie Rating Categories
4. **Histogram** — Distribution of Movie Ratings
5. **Scatter Plot** — Movie Year vs Rating

## Files

* `movies_cleaned.csv` — Cleaned movie dataset
* `visualization.py` — Python visualization script
* `01_movies_by_genre.png` — Bar chart
* `02_movies_by_year.png` — Line chart
* `03_rating_categories.png` — Pie chart
* `04_rating_distribution.png` — Histogram
* `05_year_vs_rating.png` — Scatter plot

## Objective

The objective of this task is to communicate important patterns and trends in the dataset through clear, labeled, and readable visualizations.
